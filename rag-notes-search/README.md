# 📓 RAG Notes Search

Семантический поиск по своим заметкам с ответами от Claude. Загружаешь
`.txt` / `.md` / `.pdf` файлы — они режутся на чанки, превращаются в
эмбеддинги и складываются в локальный векторный индекс. Дальше можно
задавать вопросы обычным языком: приложение находит релевантные по
**смыслу** (а не по ключевым словам) фрагменты и просит Claude ответить
строго на их основе, с указанием источников.

## Как это работает

1. **Chunking** — текст режется на фрагменты ~800 символов по границам
   предложений, с перекрытием, чтобы не терять контекст на стыках
   (`backend/app/chunking.py`).
2. **Embeddings** — каждый чанк превращается в вектор локальной моделью
   `BAAI/bge-small-en-v1.5` через [fastembed](https://github.com/qdrant/fastembed)
   (ONNX, без тяжёлого PyTorch, без внешнего API). Запросы и документы
   эмбеддятся асимметрично (`query_embed` / `passage_embed`) — это
   стандартный приём для bge-моделей, повышающий качество поиска.
3. **Vector store** — простое numpy-хранилище с косинусной близостью,
   персистится на диск (`backend/data/`). Для личной коллекции заметок
   этого достаточно, не нужен внешний Vector DB.
4. **Generation** — топ-K релевантных чанков передаются в Claude вместе с
   системным промптом, который запрещает выходить за пределы источников
   и требует проставлять цитаты `[1]`, `[2]`.

## Запуск

```bash
cd rag-notes-search/backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите свой ANTHROPIC_API_KEY в .env

uvicorn app.main:app --reload --port 8000
```

Открыть `http://localhost:8000` — бэкенд сам раздаёт фронтенд из
`../frontend`. Отдельный сервер для фронта не нужен.

При первом запуске `fastembed` скачает ONNX-модель эмбеддингов (~130 МБ)
и закэширует её локально — нужен доступ в интернет один раз.

## API

| Метод    | Путь                  | Описание                          |
|----------|-----------------------|------------------------------------|
| `GET`    | `/api/documents`      | Список загруженных документов      |
| `POST`   | `/api/documents`      | Загрузить файл (`multipart/form-data`, поле `file`) |
| `DELETE` | `/api/documents/{id}` | Удалить документ и его чанки       |
| `POST`   | `/api/query`          | `{"question": "..."}` → ответ + источники |

## Стек

FastAPI · fastembed (ONNX embeddings) · numpy · Anthropic SDK (Claude) ·
ваниль HTML/CSS/JS без сборки.
